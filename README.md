# PixelTime

Çalış, Pixel'i ortaya çıkar! Çalıştığın her 25 dakika, Pixel'in tuvalinden bir kare açar.

- **Pomodoro ve kronometre:** 25 dk = 1 kare. Çalışırken uygulamadan çıkarsan Pixel kaçar.
- **Profil:** takma ad, 32 kuş avatarı, istediğin kare rengi; isteğe bağlı sınav, şehir, okul.
- **Ekipler:** 2-10 kişi, kişi sayısına göre büyüyen ortak tuval, davet linki.
- **Sıralama:** kişiler, okullar, şehirler, ekipler; haftalık, aylık, tüm zamanlar.
- **Sezon kartı:** hikâyede paylaşılacak kart.
- **İnternetsiz çalışır,** ana ekrana uygulama olarak eklenebilir.

Kurulum için `KURULUM.md`'ye bak.

Pixel'in anısına.
