# PixelTime

Çalış, Pixel'i ortaya çıkar! Her tamamlanan pomodoro, Pixel'in tuvalinden bir kare açar.

- Pomodoro sırasında uygulamadan çıkmak yasak: çıkarsan Pixel kaçar.
- İnternetsiz çalışır, ana ekrana uygulama olarak eklenebilir.
- Test modu: adresin sonuna `?test` ekle (1 sn pomodoro, 16 kare).

Pixel'in anısına.
